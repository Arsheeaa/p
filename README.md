# Arshia Portfolio — Static HTML/CSS/JS

## Important
This version loads content from JSON files. For normal use, upload the whole folder to a web host. Opening `index.html` directly with `file://` may block JSON loading in some browsers.

## Edit content
- `assets/data/profile.json`
- `assets/data/projects.json`
- `assets/data/skills.json`

## Images
Put project images in `assets/images/` and set the filename in `projects.json`.

## Phone testing
For the easiest phone preview, upload the folder to any static hosting or your own cPanel hosting, then open the domain on the phone. The layout has a dedicated mobile navigation and mobile-specific spacing/interactions.
