# GitHub Pages upload

1. Create a new GitHub repository.
2. Open the repository and choose **Add file → Upload files**.
3. Extract the ZIP first, then upload the **contents** of this folder (not the folder itself). `index.html` must appear in the repository root.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.
7. Wait for the deployment message and open the URL GitHub shows.

## Editing content
- `assets/data/projects.json` → projects
- `assets/data/skills.json` → skills
- `assets/data/profile.json` → profile text

The site is static and does not need PHP, a database, or a separate web server.
